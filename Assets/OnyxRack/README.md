# Anchored ONYX rack artwork

`chassis.png` is a 1536 x 1024 decorative perimeter skin generated with the
built-in image_gen tool from the user's SURGERY EQ reference images. It is
embedded in the Windows plugin; no external skin installation is required.
All text, analyzer curves, knobs and controls are drawn live by JUCE.

Reference images: ONYX Surgery EQ Rack Interface.png and
Spiral Ether Tech Surgery EQ Interface.png, supplied by the user.

## Final generation prompt

Create a production GUI decorative BACKGROUND ASSET based on these reference images, not a complete mockup. Landscape 3:2, straight-on orthographic, sharp high resolution. Preserve the industrial ONYX rack chassis aesthetic: realistic scratched gunmetal outer perimeter, chamfered silver machined edges, small recessed screws in corners and side rails, black steel, restrained amber/yellow hazard stripe inserts ONLY on narrow left/right rails in upper half, subtle cyan edge reflections. Exact composition: perimeter frame occupies only outermost 4% left and right and outermost 3% top and bottom, leaving a completely EMPTY flat near-black (#03090c) rectangular interior from x=5% to95%, y=4% to96%. All details belong to perimeter only. Inner area must have NO controls, NO graph, NO knobs, NO divisions, NO typography, NO logos, NO numeric markings. Top center metal rail blank for live engraved text to be added by software. No perspective tilt, no room/environment, no drop shadow outside frame, full canvas filled by chassis. Match the reference hardware material richness and precision, realistic brushed highlights and fine scratches without excessive grime. This image will sit behind separately rendered working plugin controls.
